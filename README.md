A token launch radar that reads a sealed DefiLlama snapshot of 758 protocols, ranks the pre-token ones by implied launch value, and serves a static dashboard with a ranked board, per-protocol detail views, filters, and concrete farm plans.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
